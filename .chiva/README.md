# Chiva

Welcome to Chiva!

Chiva is the ultimate tool for managing your development workflow, enforcing standards, and ensuring environment integrity.

## What's in here?

- `.chiva/`: Contains project-specific configurations for Chiva.
- `.chiva/hooks/`: Contains Git hooks configured by Chiva to automate your workflow.
